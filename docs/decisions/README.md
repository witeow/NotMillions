# Architecture Decision Records

Short records of the significant decisions in this project: the situation that forced a choice, the choice made, and what it commits us to. Read the relevant ADR before changing core design; if a decision is reversed, don't edit the old record — add a new ADR that supersedes it and update the old one's status.

Format per record: **Context** (the forces at play), **Decision** (what we chose and why), **Consequences** (what follows, good and bad).
